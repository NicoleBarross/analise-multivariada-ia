# analise-multivariada-ia
## Fonte dos dados e referência bibliográfica

Os dados utilizados neste projeto foram obtidos do conjunto *Study habits and artificial intelligence use among university students: A proportionally stratified survey dataset*, disponibilizado por Cristian Correa no repositório Mendeley Data.

**Referência bibliográfica:**

CORREA, Cristian (2026). *Study habits and artificial intelligence use among university students: A proportionally stratified survey dataset*. Mendeley Data, V1. DOI: [10.17632/mcwb2ppdsw.1](https://doi.org/10.17632/mcwb2ppdsw.1).

Neste projeto, utilizamos principalmente o arquivo `survey_cleaned_english.csv`, além do dicionário de variáveis e do questionário disponibilizados junto ao conjunto original de dados.
